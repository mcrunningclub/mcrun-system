---

#### ## <big> getUserTimeZone() </big>

Returns the timezone for the script as a geographical location string.

```js
const tz = getUserTimeZone();
```

| Name | Type   | Description |
|------|--------|-------------|
| —    | —      | No parameters |

**Output:** String (timezone, e.g., 'America/Montreal')

**Pitfalls:** None
